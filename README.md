# Favour portfolio

Open this folder in Visual Studio Code.

The site uses plain HTML, CSS and JavaScript. No npm install or build step is required.

## Preview
Open index.html in a browser, or use VS Code's Live Server extension and choose Open with Live Server on index.html. A local server is recommended for development.

## Edit
- index.html: page content and project information
- style.css: colours, layouts, typography and animations
- script.js: navigation, galleries, motion controls and contact form
- images/, fonts/, icons/: required local assets; keep these folders beside index.html
- licenses/: font and icon licenses

The homepage and Explore control are preserved. Inner pages use burgundy/plum colours and glass panels without scenic background images.

MamaCare content is provisional and awaits your updated README and screenshots. The existing EmailJS setup is retained; real message delivery has not been tested. Internet access is needed for external project links and sending the contact form.

Fonts: Instrument Serif and Manrope (Google Fonts). Icons: Remix Icon. Homepage scene and balloon art were generated for this portfolio. Project screenshots came from the supplied portfolio.
